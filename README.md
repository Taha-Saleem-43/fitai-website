# FitAI Website

A standalone, dependency-free landing page for FitAI. It is intentionally separate from the Flutter app repository.

## Preview locally

Open `index.html` in a browser, or use any static-file server.

## Deploy to GitHub Pages

1. Create an empty GitHub repository named `fitai-website` (or another preferred name).
2. Copy these files into that repository root and push to the `main` branch.
3. In GitHub: **Settings → Pages → Build and deployment → Deploy from a branch**.
4. Select `main` and `/ (root)`, then save.
5. GitHub will provide a public URL such as `https://<username>.github.io/fitai-website/`.

Before public launch, replace `hello@fitai.app` in `index.html` with a working contact email, if available.
